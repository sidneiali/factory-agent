# Adicao — Reversa Bridge 0.3.0

## Objetivo

Integrar o Factory Agent aos artefatos produzidos pelo Reversa para que uma extracao de engenharia reversa possa orientar, com curadoria e rastreabilidade, a construcao de um sistema novo.

## Alteracoes realizadas

- Adicionados detector, validador e snapshot imutavel de saidas Reversa.
- Criados `factory import reversa` e `factory new --from-reversa`.
- O snapshot registra SHA-256, tamanho, confianca, origem, versao e timestamp.
- A origem legada e a saida Reversa permanecem somente leitura e separadas da raiz alvo.
- Adicionados 8 agentes de importacao, curadoria, requisitos-alvo, arquitetura-alvo, dados, paridade, cutover e rastreabilidade.
- O workflow passou a rotear reconstrucao, QA de paridade e cutover.
- A extensao Pi recebeu dois comandos e duas ferramentas com confirmacao humana.
- O runtime Ollama passou a consumir o snapshot pelo contexto verificado existente.
- Updates instalam automaticamente agentes adicionados em versoes novas.
- Versao atualizada para `0.3.0` e documentacao ampliada com o guia Reversa Bridge.

## Validacoes executadas

- `npm run check`: 28 testes aprovados.
- 22 skills com front matter e nomes validados.
- Sintaxe JavaScript e schemas JSON validados.
- Links Markdown internos validados.
- Importacao testada com pasta de saida configuravel e tambem com path direto.
- Snapshot validado com hashes SHA-256 e comparacao da origem antes e depois.
- Extracao incompleta e raiz alvo aninhada no legado foram recusadas.
- Fluxo temporario `install → import reversa → new --from-reversa → status → doctor` aprovado.
- Extensao TypeScript carregada pelo Pi Agent real.
- `npm pack --dry-run` confirmou 68 arquivos no pacote `0.3.0`.
- Ollama local respondeu ao teste de conexao com 6 modelos.
- O runtime recebeu o snapshot em teste de chat Ollama simulado.

## Limitacao observada

Duas tentativas de gerar a proposta de curadoria com modelos Ollama locais reais expiraram por timeout. A descoberta e conectividade do servidor funcionaram, mas a geracao completa nao foi validada neste ambiente. O timeout pode ser configurado por `factory provider select ollama --timeout=<ms>`.
