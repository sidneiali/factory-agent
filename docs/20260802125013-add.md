# Adição — documentação completa do Factory Agent

## Objetivo

Criar uma documentação própria e navegável para o Factory Agent, usando a organização temática do Reversa como referência, e remover o clone local que serviu de fonte de consulta.

## Alterações realizadas

- Adicionada configuração `mkdocs.yml` sem plugins ou dependências obrigatórias.
- Criadas páginas de início, instalação, uso, CLI, configuração, engines, providers, workflow, agentes, segurança, troubleshooting, arquitetura e contribuição.
- Atualizado o README com o ponto de entrada da documentação.
- Registrado e concluído o plano aprovado em `doc/plan.md`.
- Removido definitivamente o diretório local `reversa/` após a validação documental.
- Removida do `.gitignore` a regra que existia exclusivamente para o clone de referência.

## Validações executadas

- `npm run check`: análise sintática e 21 testes automatizados aprovados.
- `node bin/factory.js --help`: aplicação CLI executada e comandos confrontados com a documentação.
- `node bin/factory.js --version`: versão `0.2.0` confirmada.
- Validação local de links Markdown em 22 arquivos.
- Validação dos 15 destinos declarados na navegação do MkDocs.
- Verificação física de que `reversa/` não existe mais.
- Revisão de `git status`, `git diff` e `git diff --check` antes do commit.

## Limitação da validação

O executável `mkdocs` não está disponível no ambiente. Nenhuma dependência foi instalada automaticamente; por isso, o site não foi renderizado. A estrutura de navegação e todos os links locais foram validados por scripts sem dependências externas.
