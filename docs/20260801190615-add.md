# Adição — Pi Agent e Ollama

## Objetivo

Adicionar o Pi Agent como engine hospedeira oficial e o Ollama como provider local e runtime direto do Factory Agent.

## Alterações realizadas

- Adicionada engine `pi-agent`, com detecção do executável `pi` e do diretório `.pi/`.
- Adicionada instalação de skills em `.pi/skills/` e da extensão local em `.pi/extensions/factory-agent/`.
- Adicionado wrapper da extensão em `.pi/extensions/factory-agent/index.ts` no próprio repositório para desenvolvimento e uso local.
- Criada extensão TypeScript para Pi Agent com comandos, ferramentas, status da TUI, persistência e gates.
- Implementado policy guard para `bash`, `write` e `edit`, com bloqueios de caminhos sensíveis e confirmação para operações de risco.
- Implementada abstração `ModelProvider` e cliente Ollama sobre `/api/tags` e `/api/chat`.
- Implementados comandos `provider`, `new`, `run`, `resume`, `approve` e `reject`.
- Implementado runtime direto com propostas estruturadas, allowlist de artefatos e aplicação somente após aprovação.
- Adicionado registro dinâmico dos modelos de chat Ollama no Pi como provider `factory-ollama`; modelos de embedding são filtrados.
- Atualizados requisitos, arquitetura, contrato dos agentes, schemas, templates, README e compatibilidade das 14 skills.
- Versão do pacote atualizada para `0.2.0`.

## Validações executadas

- Testes focados do provider Ollama, runtime, CLI, instalação Pi e policy guard.
- Extensão TypeScript carregada pelo Pi Agent `0.83.0` em projeto temporário e pelo wrapper local do repositório.
- Policy guard executado dentro do loader real do Pi, comprovando casos `allow`, `confirm` e `block`.
- Suite completa `npm test`: 21 testes aprovados, sem skips.
- Ollama `0.32.1` detectado e consultado no endpoint local: 6 modelos encontrados.
- Chat real executado pelo runtime com `qwen3-software:latest`: proposta válida para `_factory_product/brief.md`, 447 tokens de entrada e 813 de saída.
- Provider `factory-ollama` carregado pelo Pi com 5 modelos de chat; `nomic-embed-text` foi corretamente excluído.
- Fluxo CLI validado em pasta temporária: `install → provider select/test → new → run → approve → resume`.

## Limitações conhecidas

- A extensão adiciona gates para ferramentas conhecidas, mas não é um sandbox do sistema operacional.
- O runtime direto não sobrescreve arquivos existentes; mudanças em código existente continuam dependentes da engine hospedeira e de gates.
- A qualidade de envelopes estruturados e chamadas de ferramentas varia conforme o modelo Ollama.
- Não há download ou instalação automática de modelos.
