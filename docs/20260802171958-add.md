# Adição — publicação do pacote npm

## Objetivo

Preparar e publicar o Factory Agent como pacote npm público, mantendo o código-fonte sincronizado com o repositório GitHub.

## Alterações realizadas

- Alterado o nome do pacote para `@sidnei_ali/factory-agent`.
- Adicionados metadados de repositório, homepage, issues e acesso público ao `package.json`.
- Documentadas execução por `npx` e instalação global com npm no README e no guia de instalação.
- Mantido o executável global `factory` e a versão `0.2.0`.

## Validações executadas

- `npm whoami`: usuário `sidnei_ali` autenticado.
- `npm run check`: análise sintática e 21 testes aprovados.
- Pacote gerado em pasta temporária e instalado em um projeto consumidor temporário.
- CLI empacotada executada com `--help` e `--version`; versão `0.2.0` confirmada.
- `npm pack` revisado antes da publicação.
- `git status`, `git diff` e `git diff --check` revisados antes do commit.

## Publicação

- Repositório: `https://github.com/sidneiali/factory-agent`.
- Pacote: `https://www.npmjs.com/package/@sidnei_ali/factory-agent`.
- A publicação e a execução pelo registry serão verificadas após `npm publish --access public`.
