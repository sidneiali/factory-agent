# Correção — colisão de skills no Pi Agent

## Objetivo

Eliminar a instalação duplicada das mesmas skills em `.agents/skills/` e `.pi/skills/`, evitando colisões de descoberta no Pi Agent.

## Alterações realizadas

- Instalações novas do Pi Agent passaram a usar somente `.agents/skills/`, diretório universal já descoberto pelo Pi.
- O update migra instalações antigas removendo cópias intactas de `.pi/skills/`.
- Cópias antigas customizadas são preservadas fisicamente e removidas do estado e manifesto gerenciados.
- A versão foi atualizada para `0.2.1`.
- README e documentação de instalação, engines, uso, arquitetura e segurança foram atualizados.
- Foram adicionados testes de instalação sem duplicação e migração segura.

## Validações executadas

- `npm run check`: 22 testes aprovados.
- Verificação sintática de todos os arquivos JavaScript.
- Parse de templates e schemas JSON.
- Instalação real em pasta temporária com `--engines=pi-agent`.
- Confirmação de `.agents/skills/factory-new/SKILL.md` e ausência de `.pi/skills/factory-new/SKILL.md`.
- Carregamento real da extensão pelo Pi Agent.
- Migração testada com cópia legada intacta e cópia customizada.
- `factory doctor` executado na instalação temporária.
- `npm pack --dry-run` confirmou o pacote `@sidnei_ali/factory-agent@0.2.1` com 56 arquivos.

## Compatibilidade

A extensão permanece em `.pi/extensions/factory-agent/`. Projetos antigos devem executar `factory update`; customizações em `.pi/skills/` não serão apagadas nem continuarão gerenciadas.
