# Adição — Factory Agent MVP

## Objetivo

Criar o MVP de uma fábrica de software multiagente voltada à criação e manutenção de aplicações, usando o Reversa somente como referência arquitetural.

## Alterações realizadas

- Criada CLI Node.js com os comandos `install`, `status`, `doctor`, `update`, `add-agent`, `add-engine` e `uninstall`.
- Implementadas detecção de Claude Code e Codex, instalação não destrutiva, estado atômico, políticas, schemas e manifesto SHA-256.
- Implementada retomada pelo estado físico dos artefatos.
- Criadas 14 skills para orquestração, produto, arquitetura, planejamento, desenvolvimento, revisão, QA, aceite, documentação, suporte e bugs.
- Adicionados requisitos, arquitetura, contrato de agentes, README e licença MIT.
- Adicionados testes unitários e de integração com projetos temporários.

## Validações executadas

- Verificação sintática de todos os arquivos JavaScript com `node --check`.
- Parse dos templates e schemas JSON.
- Validação estrutural dos front matters das 14 skills.
- Testes focados de core, workflow, instalador e CLI.
- Suite completa com `npm test`: 10 testes aprovados.
- Instalação real em pasta temporária com Claude Code e Codex.
- Execução de `status` e `doctor` na instalação temporária.
- Teste de update preservando uma skill customizada.
- Teste de uninstall preservando o arquivo customizado.

## Limitações conhecidas

- O MVP é CLI e não possui interface web.
- Skills são executadas pela engine hospedeira; a CLI não fornece sandbox para comandos da engine.
- Não há scheduler remoto, integração direta com APIs de LLM ou deploy automático.
